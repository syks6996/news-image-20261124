A program that draws one 1024x1024 newspaper front page summing up Tuesday 24 November 2026: the Houthi strike on Riyadh's tallest tower, Russia's open-war warning to Estonia, the Gaza strike that killed Hamas security chief Naeem Abu Nahel, the COP31 climate summit ending with no deal, Nvidia bringing back Jensen Huang as CEO, and Senegal's restored Africa Cup of Nations title. Pure Node 22 standard library — a hand-written 5x7 bitmap font, a small raster canvas and a minimal PNG encoder — so two runs write byte-identical files with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
